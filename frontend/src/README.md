# Frontend source modules

Este diretório é reservado para futuros módulos JavaScript do frontend.

A ideia é migrar o código monolítico de `frontend/public/script.js` para arquivos menores, como:
- `frontend/src/menu.js`
- `frontend/src/cart.js`
- `frontend/src/checkout.js`
- `frontend/src/admin.js`
- `frontend/src/utils/*.js`

Por enquanto, a aplicação serve os arquivos estáticos existentes em `frontend/public/`.
